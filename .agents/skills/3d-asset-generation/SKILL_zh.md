# 3D 资产生成

当制作需要真实网格而非原始占位体时使用本技能。
它与 `threejs-world-generation` 互补：后者负责语义化世界规划；
本技能负责唯一网格与重复网格如何带着溯源信息进入世界。

## 按资产角色路由

| 需求 | 工具 | 模型/路径 | 原因 |
|---|---|---|---|
| 重复植被、岩石、通用道具 | `threejs_asset_catalog` | CC0 Kenney catalog | 免费、风格统一、适合实例化 |
| 用文字描述的唯一物体 | `atlas_3d` | `tripo-h3.1/text-to-3d` | 直接输出带纹理/PBR 的 GLB，支持种子与面数上限 |
| 与概念图匹配的物体 | `fal_3d` | Hunyuan 3D v3.1 Rapid image-to-3D | 单张图对轮廓/风格约束更好 |
| 从一张区域构图提取多个物体 | `fal_3d` | SAM 3D Objects | 单独与合并 GLB 及摆放元数据 |
| 地形、构图、光照、相机、最终帧 | `blender_world` | Blender 4.5 LTS / Eevee Next | 场景级控制；生成式 3D API 不是世界渲染器 |

切勿要求 text-to-3D 模型一次生成整片电影级世界网格。
生成英雄物体，用授权目录做大批量散布，并在 Blender 中按语义规格组装一切。

## 付费调用纪律

在每次首次调用供应商前，说明确切的供应商、模型、操作、
预估单价以及请求的输出数量。批量前先做一个样本。截至 2026-08-13：

- Atlas Tripo H3.1：无纹理 $0.22；标准纹理 $0.33；HD
  纹理 $0.44；精细几何另加 $0.22；四边网格另加 $0.055。
- fal Hunyuan 3D v3.1 Rapid：每次生成 $0.225；PBR 另加 $0.15。
- fal SAM 3D Objects：每次重建 $0.02。

价格会变。报价或跑批量前请确认供应商页面。

## 资产提示词契约

每次请求描述一个孤立物体，而非一个镜头：

1. 命名物体与轮廓。
2. 说明构造材质与可见磨损。
3. 说明项目的艺术风格与色彩约束。
4. 说明尺度与朝向。
5. 排除地面、背景、额外物体、标签与灯光装置。

对 image-to-3D，使用简单背景，让物体占画面一半以上。
仅对足够近、能从 PBR 受益的资产请求 PBR。

## 强制网格 QA

不要仅凭供应商缩略图批准。将下载产物导入 Blender 并检查：

- 正面、背面与轮廓；
- 几何破洞与悬浮碎块；
- 接地、尺度与朝向；
- UV 接缝与缺失纹理槽；
- base-color、roughness、metallic 与 normal 响应；
- 三角面数及预期相机距离是否匹配。

在资产溯源清单中记录供应商、模型 id、提示词、种子、来源页、成本与输出路径。
失败样本保持失败；不要静默换供应商或在另一模型上再花钱。

### 组装归一化是强制的

供应商与目录 GLB 很少共享单位、原点或 up 轴假设。
切勿用任意场景级缩放猜测补偿。Blender 组装规格声明 `target_height`；
渲染器测量导入包围盒，归一化到该目标，并将包围盒底面偏移到采样地形高度。
复核所得真实世界尺度与接地。

重复散布必须在聚落、道路、河流、地标开口与英雄相机视线周围声明语义 `exclusion_zones`。
遮挡主体的密度不算生产细节。水道与路径须用贴地 flat 带状面；
倒角 3D 曲线从航拍相机会读成管道。

揭示时机重要的地标在场景规格中声明可见性窗口。
相机遮挡仍是自然揭示的首选，但确定性可见性关键帧才是批准时机的硬保证。

## 世界保真度预算

参考级区域需要三层同时存在的密度：

- macro：人工地形轮廓、水道、路径、聚落；
- meso：英雄建筑、桥梁、悬崖、树冠簇、道具；
- micro：地表覆盖、岩石、花、碎屑、材质层次变化。

资产关卡须展示全局、区域与步行高度 Blender 静帧。
仅宽航拍会掩盖错误接触；仅步行镜头会掩盖空世界。
仅基元预览须标为 `blockout`，不能作为生产保真评审通过。

最终动画先渲染小范围有界帧并测量每帧时间。
根据测量选全片渲染分辨率，而非凭直觉；渲染编号 PNG 序列；
中断后对 `blender_world` 使用 `resume: true`，从首个缺失帧继续。
