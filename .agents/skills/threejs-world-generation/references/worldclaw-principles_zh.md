# 适用于 OpenMontage 的 WorldClaw 原则

来源：[WorldClaw: Agentic 3D Open-World Generation at Scale](https://arxiv.org/html/2608.05248v1)，Guo 等，arXiv:2608.05248v1（2026）。

WorldClaw 的公开仓库目前包含论文与资源，不包含可执行的生成栈。因此 OpenMontage 采用其架构思想，而非私有代码或模型权重。

## 可迁移的架构

1. **意图提取先于补全。** 将用户明确陈述的事实与推断出的构造参数分开维护。
2. **共享的结构化中间表示协调各智能体。** 世界规格（world spec）在各阶段传递区域、地形、物体、外观与空间关系。
3. **全局约束先于局部细节。** 一次性确立语义布局、尺度、地形、氛围与主要关系。
4. **地形是空间契约。** 高度、调色、散布与后续放置使用同一套区域权重。
5. **可复用的环境原型与功能性地标不同。** 在全球范围内散布岩石、植被与晶体；显式放置具名结构。
6. **局部开发要有选择性。** 将细节与迭代集中在对镜头路径或交付承诺重要的区域。
7. **物体保持独立。** 稳定的 ID 与变换保留可编辑性与可替换性。
8. **放置需感知接触。** 采样地形高度与坡度，拒绝不合理候选，对齐实例，并诊断悬空或穿透。
9. **精修以渲染为引导且受边界约束。** 使用全局、区域、行走、语义与线框视图；只改动责任范围最窄的参数。
10. **可执行表示提升复用性。** 代码原生的地形、材质、放置与镜头路径保持参数化与可动画化。

## 本地映射

| WorldClaw 概念 | OpenMontage 实现 |
|---|---|
| 结构化场景规格 | `world_spec` JSON 与工具 schema |
| 语义布局图 | 连续归一化的区域权重场 |
| 区域感知高度场 | 加权程序化地貌算子 |
| 地形材质 | 块化阶段：顶点色。生产阶段：目录化 PBR 纹理层 |
| 可复用地形资产 | 块化阶段：基元。生产阶段：授权纹理 GLTF/GLB 调色板 |
| 区域物体 | 稳定的显式场景节点；生产阶段禁止基元地标回退 |
| Blender 精修智能体 | HyperFrames 快照加智能体问题队列 |
| 自由视点渲染 | 响应 `hf-seek` 的确定性 Three.js 镜头路径 |
| 可编辑纹理网格 | 可编辑的代码原生几何、材质、区域与变换 |

## 刻意的范围差异

- 无单视图物体重建、分割或生成的 PBR 纹理贴图。
- 当前可运行路径不依赖 Blender 或 Unreal；这限制了重建与离线渲染保真度。
- 不声称具备可与大型生成式 3D 模型媲美的照片级资产多样性。
- 对浏览器渲染的 OpenMontage 视频工作，强调更强的可移植性与确定性。
