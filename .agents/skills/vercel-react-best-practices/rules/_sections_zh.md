# 章节

本文件定义所有章节及其顺序、影响级别和描述。
章节 ID（括号内）是用于对规则进行分组的文件名前缀。

---

## 1. 消除瀑布流 (async)

**影响：** 关键  
**描述：** 瀑布流（waterfall）是排名第一的性能杀手。每个顺序 `await` 都会叠加完整的网络延迟。消除瀑布流能带来最大收益。

## 2. 打包体积优化 (bundle)

**影响：** 关键  
**描述：** 减小初始打包体积可提升可交互时间（Time to Interactive）和最大内容绘制（Largest Contentful Paint）。

## 3. 服务端性能 (server)

**影响：** 高  
**描述：** 优化服务端渲染与数据获取可消除服务端瀑布流并缩短响应时间。

## 4. 客户端数据获取 (client)

**影响：** 中高  
**描述：** 自动去重与高效的数据获取模式可减少冗余网络请求。

## 5. 重渲染优化 (rerender)

**影响：** 中  
**描述：** 减少不必要的重渲染可降低无效计算并提升 UI 响应性。

## 6. 渲染性能 (rendering)

**影响：** 中  
**描述：** 优化渲染过程可减少浏览器需要完成的工作。

## 7. JavaScript 性能 (js)

**影响：** 低中  
**描述：** 针对热路径的微优化累积起来可带来可观的提升。

## 8. 高级模式 (advanced)

**影响：** 低  
**描述：** 适用于特定场景、需要谨慎实现的高级模式。
