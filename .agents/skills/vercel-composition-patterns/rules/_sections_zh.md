# 章节

本文件定义所有章节及其顺序、影响级别与描述。
括号中的章节 ID 是用作规则分组文件名的前缀。

---

## 1. 组件架构 (architecture)

**影响：** 高  
**描述：** 用于组织组件的基础模式，避免 props 泛滥并支持灵活组合。

## 2. 状态管理 (state)

**影响：** 中  
**描述：** 在组合式组件之间提升状态并管理共享上下文的模式。

## 3. 实现模式 (patterns)

**影响：** 中  
**描述：** 实现复合组件与 context 提供者的具体技巧。

## 4. React 19 API (react19)

**影响：** 中  
**描述：** 仅适用于 React 19+。不要使用 `forwardRef`；用 `use()` 替代 `useContext()`。
