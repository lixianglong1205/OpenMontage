# 章节

本文件定义所有章节及其顺序、影响级别和描述。
括号中的章节 ID 用作分组规则的文件名前缀。

---

## 1. 核心原则 (core)

**影响：** 关键
**描述：** 适用于所有 FLUX 模型的通用提示原则。在深入具体技巧之前，请先掌握这些内容。

## 2. 模型选择 (model, flux2, flux1)

**影响：** 高
**描述：** 根据使用场景选择合适的 FLUX 模型。涵盖 FLUX.2（最新）与 FLUX.1（旧版）两个模型系列。

## 3. 文生图提示 (t2i)

**影响：** 高
**描述：** 如何撰写从文本描述生成图像的有效提示。

## 4. 图生图编辑 (i2i)

**影响：** 高
**描述：** 使用 FLUX.2 模型编辑与变换现有图像的技巧。

## 5. JSON 结构化提示 (json)

**影响：** 中高
**描述：** 使用结构化 JSON 构建复杂多元素场景。

## 6. 颜色规范 (hex)

**影响：** 中
**描述：** 使用十六进制色码精确控制颜色，以实现符合品牌的生成效果。

## 7. 排版与文字 (typography)

**影响：** 中
**描述：** 在生成图像中渲染文字与排版。

## 8. 多参考图编辑 (multi)

**影响：** 中
**描述：** 组合多张参考图进行风格迁移与画面合成。

## 9. 正向提示替代方案 (negative)

**影响：** 中
**描述：** 在 FLUX 不支持负向提示的前提下，仍达成预期效果的策略。
