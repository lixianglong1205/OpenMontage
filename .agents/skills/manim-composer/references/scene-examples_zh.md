# 分镜示例

来自 3Blue1Brown（3b1b）风格视频的分镜拆解示例。

---

## 示例 1：讲解点积

### 场景 1：提出问题
**时长**：约 30 秒  
**目的**：用悬念抓住观众

**视觉元素**
- 两个向量 a 和 b，以箭头形式绘制
- 点积公式：a · b = |a||b|cos(θ)
- 问号动画

**内容**
开场展示两个向量。显示公式。抛出疑问：「为什么把分量相乘再相加，会得到与向量夹角相关的结果？」

**旁白要点**
语气：好奇、略带困惑。强调公式看起来似乎很随意。

**技术要点**
- 用 `Arrow` 表示向量
- 用 `MathTex` 显示公式
- 对 `cos(θ)` 项使用 `Indicate()`

---

### 场景 2：几何解释
**时长**：约 90 秒  
**目的**：展示投影解释

**视觉元素**
- 向量 a（水平，蓝色）
- 向量 b（倾斜，绿色）
- b 在 a 上的投影（虚线）
- 直角标记
- 长度标注

**内容**
说明 a · b 等于 |a| 乘以 b 在 a 方向上的投影长度。动画演示投影「落下」。从几何上说明这等于 |a||b|cos(θ)。

**旁白要点**
「点积衡量一个向量在另一个向量方向上有多少分量。」

**技术要点**
- 投影用 `DashedLine`
- 直角用 `RightAngle` mobject
- 用 `animate.rotate()` 展示不同夹角

---

### 场景 3：与代数建立联系
**时长**：约 60 秒  
**目的**：把几何与代数联系起来

**视觉元素**
- 坐标网格
- 向量 a = [a₁, a₂]
- 向量 b = [b₁, b₂]
- 高亮分量

**内容**
在网格上展示向量并标注分量。说明为何 a₁b₁ + a₂b₂ 与几何解释一致。使用具体数值演示。

**旁白要点**
慢慢推导计算。「我们来看看代数为何与几何一致。」

**技术要点**
- `NumberPlane` 或 `Axes`
- 分量标签用 `Brace`
- 公式步骤用 `TransformMatchingTex`

## 示例 2：傅里叶级数入门

### 场景 1：钩子
**时长**：约 45 秒  
**目的**：展示令人惊讶的结果

**视觉元素**
- 方波（尖角）
- 光滑正弦波之和
- 二者之间的 morph 动画

**内容**
「你可以用完全光滑的正弦波，拼出带尖角的方波。」先展示结果，再承诺解释原理。

**旁白要点**
语气：惊奇、略带难以置信。要让观众感到意外。

**技术要点**
- 波形用 `ParametricFunction`
- morph 用 `Transform` 动画
- 可考虑展示 1、3、5 项逐项叠加

---

### 场景 2：基本构件
**时长**：约 120 秒  
**目的**：引入正弦波作为基

**视觉元素**
- 单一正弦波
- 频率可视化（振荡更快）
- 振幅可视化（更高/更矮）
- 相位可视化（左右平移）

**内容**
介绍三个参数：频率、振幅、相位。分别展示，再组合。

**旁白要点**
放慢节奏。「正弦波有三个可以调节的旋钮……」

**技术要点**
- 用 `ValueTracker` 驱动参数动画
- 用 `Updater` 让波形随 tracker 变化
- 为各参数加标签

---

### 场景 3：叠加
**时长**：约 90 秒  
**目的**：说明波可以相加

**视觉元素**
- 两条正弦波（不同颜色）
- 它们的和（第三种颜色）
- 逐点相加的可视化

**内容**
说明相加即在每一点把高度相加。用两个具体频率组合演示。

**旁白要点**
「叠加波形很简单——在每一点，把高度加起来就行。」

**技术要点**
- 三条函数图组成 `VGroup`
- 在特定 x 处用竖线表示相加
- 动画演示相加过程

## 示例 3：矩阵作为线性变换

### 场景 1：网格变换
**时长**：约 60 秒  
**目的**：建立视觉基础

**视觉元素**
- 二维坐标网格（`NumberPlane`）
- 基向量 î 与 ĵ（彩色箭头）
- 网格线随变换移动

**内容**
展示网格。高亮 î (1,0) 与 ĵ (0,1)。施加变换——观察整个网格移动，并跟踪基向量落点。

**旁白要点**
「看看施加这个变换后网格会怎样。注意每个点如何移动。」

**技术要点**
- 使用网格线可见的 `NumberPlane`
- `apply_matrix()` 方法
- 基向量在视觉上保持区分

---

### 场景 2：基向量决定一切
**时长**：约 90 秒  
**目的**：核心洞见

**视觉元素**
- 变换后的 î 与 ĵ
- 任意向量 v 的线性组合
- v = xi + yj 的可视化

**内容**
说明只要知道 î 和 ĵ 变到哪里，就能知道任意向量变到哪里。因为 v = xi + yj，变换后的 v = x(新 î) + y(新 ĵ)。

**旁白要点**
「关键洞见在这里……」在揭晓前营造期待。

**技术要点**
- 向量加法动画（首尾相接）
- 系数缩放动画
- 组合关系用 `TransformMatchingShapes`

## 场景转场模式

### 缩放聚焦
```
Full scene → Zoom into detail → Explain → Zoom out
```

### 并排构建
```
Empty left | Empty right
Add to left | Compare
Add to right | Connect them
```

### 变换链
```
Object A → Transform → Object B → Transform → Object C
(Maintain visual continuity throughout)
```

### 清空再构建
```
Complex scene → Clear/fade most → Focus on one element → Build new complexity
```
