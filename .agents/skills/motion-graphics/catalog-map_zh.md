# Director → 目录块映射（复用优先）

Builder 的**默认做法是组合现有 HF 目录块，而非手写。** `npx hyperframes add <block>` 会把块的源码放入 `compositions/`；Builder 随后**就地定制** — 多数块把内容/数据写进各自脚本（只有少数暴露 CSS 变量 `params`），因此复用 = **添加 + 编辑**，而非纯变量注入。仅在手写以下两类时例外：(a) 没有任何块能覆盖的空缺，以及 (b) 资产融合（RWA）的 affordance 绑定。

在将意图归类 → category 之后，**Director 在镜头计划 IR 中指定块名 + 定制项**：

```jsonc
"content": { "block": "data-chart", "customize": { "data": [...], "headline": "…", "palette": ["…"] } }
```

## 复用机制

- `npx hyperframes add <block>` → 源码落在 `compositions/<block>.html`；内联或通过 `data-composition-src` 引用；就地定制内容/数据/调色板/位置。
- 块以固定画布交付（1920×1080 / 1080×1920 / 1080×1080）— 匹配或适配。
- 块已遵循 HF 契约（暂停时间轴、seek）— 保持如此。

## 资产融合：借用 + 全新（唯一真正的 net-new IP）

借用 `north-korea-locked-down` 的标注 _语言_；全新部分是 RWA 融合 _逻辑_（见 RWA 研究）：

1. 分类数据类型；读取资产的 **几何 affordance** — 线性 → 时间轴/仪表、体积/纹理 → 饼图、高度 → 柱、容器 → 爆炸视图。
2. **`element_positions`** — 测量资产特征（中心 / 范围 / 安全区 / 避让区）。这是逆向步骤（vision）；在原型中多为手工估计。
3. 从资产 **吸色调色板**（勿用通用 #FFF/#000）。
4. **两层** — 资产（z0，全幅）+ 与其几何融合的数据图形（z1+），由 `element_positions` 锚定；连接线/涂鸦在物理上把数据绑到资产；资产始终可见。
