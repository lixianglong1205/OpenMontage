## 设计原则

字体不是装饰——它是结构。
张力制造注意力。
有意地打破网格。
每一次碰撞都经过编排。

## 连接器

### HeyGen Video Agent
原样使用 `style_prompt_full`。强调：凌厉切割、静态纹理、
撞入画面的字体。不要平滑过渡。广播电视控制室美学。

### HTML Slides
深色背景（#1A1A1A）。压缩字体出血至边缘。
不对称布局。红色强调。密集信息展示。

### paper.design
刻意打破网格。让字体与边缘碰撞。
使用图像碎片，而非整张照片。控制室叠加层美学。

### Figma
颜色样式：`brand/charcoal`、`brand/dirty-white`、`accent/signal-red`、`accent/electric-blue`。
文字样式：展示用压缩黑体字重。允许字体超出画框。
