# 动态数据

针对视频合成中数据与统计指标的轻量指南。美学层面见 `house-style.md`；本文只处理与数据相关的常见坑。

## 视觉连贯性

当连续出现的统计指标属于同一概念（Q1 → Q2 → Q3 → Q4，或同一产品的三项指标）时，应保持在同一视觉空间、同一美学风格下，仅数值发生变化。美学上的变化应表示新概念，而不只是换了一个数字。

## 数字需要视觉重量

单独一个数字会漂浮在空白里。每个指标都应搭配能赋予其存在感的视觉元素——比例填充条、背景色变化、代表数值的形状、进度环等。视觉不必是图表，但需要撑满画面，让数据可感，而不只是背景上的文字。

## 避免网页模式

- **不要用饼图** — 难以比较，像 PowerPoint
- **不要用多轴图表** — 观众无法在 3 秒内研究交点
- **不要用六宫格仪表盘** — 2–3 个相关指标并排可以，6 个以上属于网页模式
- **不要网格线、刻度或图例** — 动态呈现中是视觉噪音，没有增益
- **不要用图表库输出** — 用 GSAP + SVG/CSS 构建，而非 D3 或 Chart.js
