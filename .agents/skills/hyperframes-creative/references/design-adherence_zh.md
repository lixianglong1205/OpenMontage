# 设计规范符合性

在创作完成后、提供预览之前，验证合成是否遵循设计规范。

若存在设计规范（`frame.md` / `design.md`），请阅读 HTML 并检查：

1. **颜色** — 合成中出现的每个十六进制色值都应在规范调色板章节中出现（无论用户如何命名：Colors、Palette、Theme 等）。标记任何自行发明的颜色。
2. **排版** — 字体族与字重与规范中的字体说明一致。不得替换。
3. **圆角** — 若规范中声明了圆角风格，`border-radius` 值须与之匹配。
4. **间距** — 若规范中声明了密度范围，`padding` 与 `gap` 值须落在该范围内。
5. **层次/深度** — 若规范中声明了深度级别，阴影用法须与之匹配（flat = 无，subtle = 轻，layered = 发光）。
6. **规避规则** — 若规范中有列出应避免事项的小节（常见标题如 "What NOT to Do"、"Don'ts"、"Anti-patterns" 或 "Do's and Don'ts"），确认合成中均未出现。

将违规项以清单形式报告。在提供预览前逐项修复。

若不存在设计规范（仅走 house-style 路径），请验证：

1. **调色板一致性** — 所有场景使用相同的背景、前景与强调色。不得按场景自行发明颜色。
2. **无惰性默认值** — 对照 `house-style.md` 中的「Lazy Defaults to Question」列表检查合成。若出现其中任一项，须是针对内容的有意选择，而非默认值。
