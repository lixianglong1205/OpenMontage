# 视觉风格库 — 20 种风格

面向 Video Agent 提示词的命名视觉风格。每种风格均受真实平面设计师启发。按情绪强度排序。

**选择风格：** 先匹配情绪，再匹配内容。自问：*「观众应该感受到什么？」*

**使用风格：** 将风格块复制到提示词的 STYLE 部分。遵循视觉语言规则——不要注入示例 B-roll 场景（会干扰 agent）。

**自定义风格：** 以下为示例。可通过组合元素、参考其他设计师、艺术运动或文化美学创建自有风格。模式：**命名风格 + 设计师参考 + 色板 + 字体 + 动效规则 + 转场。**

## 1. Soft Signal — Stefan Sagmeister

**情绪：** 亲密、温暖 | **最适用：** 个人故事、身心健康、反思

- 暖琥珀与奶油色，点缀 dusty rose、sage green、honey gold
- 手写风格文字叠加—— personal、小写、 delicate
- 特写构图：手、脸、质感。微距镜头感
- 缓慢漂移与浮动，从不 snap。柔和 dissolve、暖色 light leak

```
STYLE — SOFT SIGNAL (Sagmeister): Warm amber/cream, dusty rose, sage green.
Handwritten-style text. Close-up framing. Slow drifts and floats.
Soft dissolves with warm light leaks.
```

## 2. Warm Grain — Olle Eksell

**情绪：** 有机、友好 | **最适用：** 环保、可持续、社区

- 大地色： ochre、forest green、terracotta、cream、soft brown
- 圆角 sans-serif 字体。有机圆角构图——无棱角
- 16mm 胶片颗粒，略去饱和。自然质感：木、亚麻、石
-  gentle wipe、soft cut、从容不迫

```
STYLE — WARM GRAIN (Eksell): Earth tones — ochre, forest green, terracotta, cream.
Organic rounded compositions. 16mm film grain. Rounded sans-serif.
Gentle wipes and soft cuts.
```

## 3. Quiet Drama — Satyajit Ray

**情绪：** 人文、沉思 | **最适用：** 人物特写、传记、文化

-  muted 暖色：sepia、deep brown、soft gold、off-white、charcoal
-  clean serif 字体，精心摆放。 portrait 构图
- 强单光源对比：窗光、单盏灯
-  deliberate 节奏，较长 hold。缓慢 fade to black

```
STYLE — QUIET DRAMA (Ray): Muted warm — sepia, deep brown, soft gold.
Portrait framing. Clean serif. Strong single-source contrast.
Slow fades to black.
```

## 4. Heritage Reel — Cassandre

**情绪：** 怀旧、复古 | **最适用：** 历史、回顾、品牌起源

- Faded gold、deep burgundy、navy、cream、sepia wash
-  elegant 居中 serif，如经典电影 title card
- Vignetting、柔化边缘。胶片颗粒、 light scratch、 gentle jitter
- Iris wipe、film reel flicker

```
STYLE — HERITAGE REEL (Cassandre): Faded gold, burgundy, navy, sepia wash.
Elegant centered serif. Vignetting and aged film grain.
Iris wipe transitions.
```

## 5. Silk Route — Reza Abedini

**情绪：** 流动、神秘 | **最适用：** 国际事务、跨文化、艺术/设计

-  rich jewel tone：deep teal、burgundy、gold、lapis blue、black
-  elegant  spaced 字体沿自然视觉线排布
-  layered 构图——前景、中景、背景均活跃
-  flowing dissolve、smooth morph

```
STYLE — SILK ROUTE (Abedini): Jewel tones — deep teal, burgundy, gold, lapis blue.
Layered compositions, all depths active. Elegant spaced type.
Flowing dissolves and smooth morphs.
```

## 6. Swiss Pulse — Josef Müller-Brockmann

**情绪：** 冷静、精确 | **最适用：** 数据密集、分析、金融、指标

- Black (#1a1a1a)、white、单一 accent：electric blue (#0066FF)
- Helvetica Bold 标题、Regular 标签。数字 LARGE（80-120pt）
- Grid-locked 构图。每个元素 snap 到 12-column grid
-  animated counter 从 0 COUNT UP。关键时刻 diagonal 构图
- Grid wipe、hard cut。无 dissolve

```
STYLE — SWISS PULSE (Müller-Brockmann): Black/white + electric blue #0066FF.
Grid-locked. Helvetica Bold. Animated counters. Diagonal accents.
Grid wipe transitions.
```

## 7. Geometric Bold — Ikko Tanaka

**情绪：** 极简、优雅 | **最适用：** 简洁生活方式、文化、视觉随笔、品牌 profile

- 每帧最多 3 种 flat color——无 gradient
- Bold clean 字体作为主要视觉元素
-  asymmetric 构图，至少 60% negative space。单一 focal point
-  on beat clean cut，无特效

```
STYLE — GEOMETRIC BOLD (Tanaka): Max 3 flat colors per frame.
60% negative space. Bold type as primary element.
Single focal point. Clean cuts on beat.
```

## 8. Velvet Standard — Massimo Vignelli

**情绪：** 高端、永恒 | **最适用：** 奢侈品、投资者更新、keynote、产品 showcase

- Black、white、单一 rich accent：deep navy (#1a237e) 或 gold (#c9a84c)
- Thin sans-serif，ALL CAPS，宽 letter-spacing
-  generous negative space。对称、居中、 architectural  precision
-  slow、deliberate。Sequential reveal。Elegant cross-dissolve

```
STYLE — VELVET STANDARD (Vignelli): Black, white, one accent: gold #c9a84c.
Thin ALL CAPS, wide spacing. Generous negative space.
Slow elegant cross-dissolves.
```

## 9. Digital Grid — Wim Crouwel

**情绪：** 系统化、技术感 | **最适用：** 基础设施、工程、代码、tech

- Dark (#0a0a0a) 配 cyan (#00E5FF)、amber (#FFB300)、green (#00FF88)
- 全程 Monospaced 字体。Code-terminal  aesthetic
- Pixel grid overlay 可见。一切 snap 到 system
- Grid node 依次点亮。Scan-line 效果、cursor blink
- Clean wipe 转场

```
STYLE — DIGITAL GRID (Crouwel): Monospaced type. Dark #0a0a0a with cyan #00E5FF, amber #FFB300.
Pixel grid overlays. Terminal aesthetic. Clean wipe transitions.
```

## 10. Contact Sheet — Alexey Brodovitch

**情绪：** 编辑感、调查 | **最适用：** 新闻、深度报道、研究拆解

- 高对比 B&W， occasional desaturated color accent
- Bold sans-serif caption，如编辑 annotation
- Photo-editorial 构图——多图、contact-sheet 能量
- Raw grain、 imperfect focus。Face 与 hand  tight crop
- On beat hard cut、snap-zoom

```
STYLE — CONTACT SHEET (Brodovitch): High contrast B&W, desaturated accents.
Photo-editorial framing. Bold sans-serif annotations. Raw grain.
Hard cuts on beat. Snap-zooms.
```

## 11. Folk Frequency — Eduardo Terrazas

**情绪：** 文化、鲜明 | **最适用：** 文化活动、美食、传统、遗产

- Vivid folk：hot pink、bright orange、cobalt blue、sun yellow、emerald
- Bold warm rounded 字体。Pattern 与 repetition——folk art rhythm
- Rich texture：woven fabric、painted surface、ceramic、handmade
- Colorful wipe、festive rhythm 上的 quick cut

```
STYLE — FOLK FREQUENCY (Terrazas): Vivid folk — hot pink, cobalt blue, sun yellow, emerald.
Bold rounded type. Folk art rhythms. Rich handmade textures.
Colorful wipes on festive rhythm.
```

## 12. Earth Pulse — Lemi Ghariokwu

**情绪：** 扎根、社群 | **最适用：** 社区、音乐/文化、grassroots

- Warm saturated：burnt orange、deep green、rich yellow、terracotta
- Bold expressive 字体，center-frame。Wide community 构图
- 与 musical beat 同步的 rhythmic 剪辑
- On beat rhythmic cut、emphasis 用 freeze-frame

```
STYLE — EARTH PULSE (Ghariokwu): Warm saturated — burnt orange, deep green, rich yellow.
Bold expressive type. Wide community framing.
Rhythmic cuts on beat. Freeze-frames.
```

## 13. Dream State — Henryk Tomaszewski

**情绪：** 超现实、诗意 | **最适用：** 评论、哲学、 think piece、 speculative

- Muted palette 加一种 surreal accent：dusty blue、grey-green，再 shock of red 或 gold
- Sparse precise 文字——少词、 maximum impact。Thin elegant floating 字体
- Unusual juxtaposition。Dreamlike：soft edge、atmospheric haze
- Slow morph dissolve。**绝不** hard cut

```
STYLE — DREAM STATE (Tomaszewski): Muted palette + one surreal accent.
Thin elegant floating type. Soft edges, atmospheric haze.
Slow morph dissolves — NEVER hard cuts.
```

## 14. Play Mode — Ahn Sang-soo

**情绪：** Playful、戏谑 | **最适用：** 娱乐、流行文化、listicle、 fun

- Bright candy：electric blue、hot pink、lime green、yellow、white
- Bouncy oversized tilted 文字。Asymmetric off-kilter 构图
- Quick cut（1-3 秒）。Score card、achievement popup、XP bar
- Bouncy spring physics——文字 overshoot 后 settle、screen shake
- Pop cut、whip pan、bounce effect

```
STYLE — PLAY MODE (Ahn Sang-soo): Electric blue, hot pink, lime green.
Bouncy spring physics. Oversized tilted text. Score cards, XP bars.
Pop cuts, bounce effects.
```

## 15. Carnival Surge — Rico Lins

**情绪：** Euphoric、庆典 | **最适用：** 重大发布、里程碑、庆祝、hype

- Maximum color：hot pink (#FF1493)、electric yellow (#FFE000)、teal (#00CED1)、orange、violet
- MASSIVE bold 文字以 ANGLES 叠在 footage 上。Collage-style overlapping
- Rapid 1-2 秒 clip。Confetti、lights、constant energy
- Smash cut、flash frame、rapid-fire montage

```
STYLE — CARNIVAL SURGE (Lins): Max color — hot pink #FF1493, yellow #FFE000, teal #00CED1.
Collage layering. Text MASSIVE at ANGLES. Confetti bursts.
Smash cuts, flash frames.
```

## 16. Shadow Cut — Hans Hillmann

**情绪：** Dark、电影感 | **最适用：** 曝光、调查、争议、 dark deep dive

- Near-monochrome：deep black、cold grey、stark white + blood red 或 toxic green
- Sharp angular 文字，如 film noir title card
- Heavy shadow——face 半明半暗、object 从 darkness 浮现
- Slow creeping push-in、slow reveal、tension
- Iris to black、slow fade from darkness、hard cut to silence

```
STYLE — SHADOW CUT (Hillmann): Deep blacks, cold greys + blood red accent.
Sharp angular text. Heavy shadow. Slow creeping push-ins.
Hard cuts to black. Film noir tension.
```

## 17. Deconstructed — Neville Brody

**情绪：** 工业、 raw | **最适用：** 科技新闻、安全、punk 能量、 counter-culture

- Dark grey (#1a1a1a)、black、rust orange (#D4501E)、raw white (#f0f0f0)
- 字体成角、 overlapping edge、 escaping frame。Bold industrial
- 高对比、gritty texture：scratched metal、peeling paint、scan-line glitch
- 文字 SLAM、SHATTER、PUNCH。Letter scramble 后 snap
- Smash cut、glitch transition、white flash frame

```
STYLE — DECONSTRUCTED (Brody): Dark grey #1a1a1a, rust orange #D4501E.
Type at angles, overlapping. Gritty textures, scan-line glitch.
Smash cuts with flash frames.
```

## 18. Maximalist Type — Paula Scher

**情绪：** Loud、kinetic | **最适用：** 重大发布、launch、high-energy recap

- Bold saturated：red、yellow、black、white——maximum contrast
- 文字即视觉。不同 scale 与 angle 的 overlapping layer，占 frame 50-80%
- Kinetic energy：一切在动、slam、slide。1-2 秒 rapid cut
- 文字 layered OVER footage——从不空背景
- Smash cut、text slam from edge、flash frame

```
STYLE — MAXIMALIST TYPE (Scher): Red, yellow, black, white — max contrast.
Text IS the visual. Overlapping at different scales, 50-80% of frame.
Kinetic everything. Smash cuts, flash frames.
```

## 19. Data Drift — Refik Anadol

**情绪：** Futuristic、immersive | **最适用：** AI/tech、speculative、cutting-edge science

- Iridescent：holographic silver、electric purple (#7c3aed)、cyan (#06b6d4)、deep black (#0a0a0a)
- Thin futuristic sans-serif——minimal、floating、weightless
- Fluid morphing 构图。Extreme scale shift：microscopic 到 cosmic
- Particle 聚合成数字、light trace data path
- Liquid dissolve、particle dispersing 并 reforming

```
STYLE — DATA DRIFT (Anadol): Iridescent — purple #7c3aed, cyan #06b6d4, deep black.
Fluid morphing compositions. Thin futuristic type.
Liquid dissolves. Particles coalesce into numbers.
```

## 20. Red Wire — David Tartakover

**情绪：** Urgent、即时 | **最适用：** 突发新闻、危机更新、alert

- High alert：red、black、white、emergency yellow——maximum contrast
- Bold condensed all caps——每个词都 scream urgency
- Split screen、ticker-style text bar、timestamp overlay——maximum information density
- 多文字元素同时出现。Handheld energy
- Snap cut、flash frame、zero breathing room

```
STYLE — RED WIRE (Tartakover): Red, black, white, emergency yellow.
Bold condensed all-caps. Split screens, tickers, timestamps.
Snap cuts, flash frames. Zero breathing room.
```
