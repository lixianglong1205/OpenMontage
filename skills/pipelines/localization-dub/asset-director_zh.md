# 资产导演 - 本地化配音流水线

## 何时使用

本阶段产出本地化资产套件：翻译后的字幕文件、配音音频、可选的口型同步渲染，以及最终输出所需的任何语言特定替换项。

## 前提条件

| 层级 | 资源 | 用途 |
|-------|----------|---------|
| Schema | `schemas/artifacts/asset_manifest.schema.json` | 制品校验 |
| 前置制品 | `state.artifacts["scene_plan"]["scene_plan"]`, `state.artifacts["script"]["script"]`, `state.artifacts["idea"]["brief"]` | 语言方案与转录包 |
| 工具 | `tts_selector`, `subtitle_gen`, `lip_sync`, `audio_enhance` — `tts_selector` 会从注册表自动发现所有可用 TTS 提供商 | 配音音频、字幕及可选口型同步制作 |
| Playbook | 当前启用的风格 playbook | 字幕与替换文本规则 |

## 流程

### 1. 优先生成字幕资产

为每种语言创建字幕或说明文字包。这样在配音生成或口型同步受阻时，仍可提供可审阅的备选方案。

### 1b. 主场景样片（强制）

在批量生成资产之前：
1. 确定主场景（视频的视觉高潮）
2. 为该场景生成一段目标语言的样片配音
3. 呈现给用户：「这是最重要场景的声线方向。是否符合你的预期？其余部分将按此风格生成。」
4. 在获得批准后再继续批量生成

这可避免最昂贵的错误：在用户不认可的方向上生成 10+ 条配音资产。

### 2. 按语言生成配音音频

使用已批准的翻译脚本包，而非原始机器输出。记录每种语言使用的音色或合成路径。

### 3. 将口型同步视为可选

仅为确实需要的场景和语言生成口型同步资产。若工具路径受阻，记录该情况并保留纯配音路径。

### 4. 用元数据承载本地化事实

推荐的元数据键：

- `subtitle_assets_by_language`
- `dub_audio_assets_by_language`
- `lip_sync_assets_by_language`
- `voice_map`
- `pronunciation_warnings`
- `blocked_assets`

### 5. 质量门禁

- 字幕资产存在，
- 计划中的配音输出具备配音音频资产，
- 口型同步明确保持可选，
- 每个被引用的文件均存在。

### 制作过程中的事实核查

若在资产生成过程中遇到不确定之处：
- 使用 `web_search` 核实主体视觉准确性（例如：该建筑实际长什么样？）
- 使用 `web_search` 在生成插图前查找参考图
- 在决策日志中记录核查：`category="visual_accuracy_check"`

视觉准确性很重要。若脚本提到特定地点、人物或物体，
在生成图像前先核实其真实外观。不要依赖
AI 模型的训练数据——可能错误或过时。

## 常见陷阱

- 在翻译审阅定稿前就开始生成配音。
- 将口型同步视为每种语言都必选。
- 未记录哪种语言资产对应哪种音色与字幕集。


## 当你不确定时

若遇到不确定的生成技巧、提供商行为或提示模式：

1. **搜索网络** 获取当前最佳实践——模型与 API 变化频繁，智能体的训练数据可能已过时
2. **查阅 `.agents/skills/`** 中已有的 Layer 3 知识（提供商专用提示指南、API 模式）
3. **若仍无法解决**，在 `projects/<project-name>/skills/<name>.md` 撰写项目范围技能，记录所学内容
4. 在技能中 **引用来源 URL**，使知识可追溯
5. **写入决策日志**：`category: "capability_extension"`, `subject: "learned technique: <name>"`

以下情况尤其重要：
- **视频生成提示**——模型随版本变化对特定词汇的响应不同
- **图像模型参数**——FLUX、GPT Image、Imagen 等的最优设置各异且持续演进
- **音频提供商特性**——语音克隆、音乐生成与 TTS 各有模型专用最佳实践
- **Remotion 组件模式**——框架演进中不断出现新的合成技巧

不要依赖过时知识。有疑问时，先搜索。

## 门禁提醒（具有约束力）

本阶段以人工批准为门禁（`human_approval_default: true`）。审阅通过后：
以 `status="awaiting_human"` 创建检查点，呈现摘要（Backlot 看板会渲染
制品），并 **结束本轮回复**。不要在同一条回复中启动下一阶段。
批准按门禁单独生效——此前说的「继续」不覆盖本门禁。
