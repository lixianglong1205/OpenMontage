# 剪辑导演 - 本地化配音流水线

## 何时使用

将场景规划与本地化素材包转化为各语言输出的具体时间线决策。目标是在可能的情况下保留源结构，同时不假设所有语言都能落在相同的时序上。

## 流程

### 1. 默认保留结构

除非译后音频明显需要延长、压缩或补画面，否则保持原始场景顺序与主要时序。

### 2. 应用所选配音模式

按交付物决定在何处：

- 保留原画面并叠加新字幕，
- 仅替换音频，
- 使用口型同步输出，
- 用图形或 B-roll 覆盖不匹配段落。

### 3. 分语言整理变体

按语言区域（locale）分别记录时间线决策，使版本管理从合成到发布全程清晰。

### 4. 用元数据控制变体

推荐元数据键：

- `locale_timeline_map`
- `timing_adjustments`
- `coverage_sections`
- `subtitle_strategy_by_locale`

### 5. 质量门

- 语言变体定义明确，
- 时序变更已记录，
- 补画面决策经过审慎考量，
- 仅在必要时才改动原始结构。

## 常见陷阱

- 强迫每种语言与源时序完全一致。
- 将各语言专用说明混在同一份含糊的剪辑清单中。
- 掩盖配音处理在视觉上较弱的段落。
