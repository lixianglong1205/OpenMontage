# 执行制片人 - 纪录片蒙太奇流水线

## 适用场景

用户希望用现有素材制作一段短（30–180 秒）、非叙事性的作品——主题拼贴、散文电影，或 Adam Curtis 式的 tone poem。作品**不是**旁白解说片，**不是**出镜讲述，**不是**单一长场景。它是由真实世界片段编排而成的序列，意义来自并置（Kuleshov 效应、爱森斯坦 intellectual montage）。

当 brief 中出现下列表述时，应选用本流水线：

- “关于……的蒙太奇”，
- “让我感受……”，
- “像 tone poem”，
- “纪录片风格拼贴”，
- “每一个曾经……的人” / “……的一生” / “……的肖像”，
- “用库存素材剪在一起”，
- “Adam Curtis”、“Errol Morris”、“Chris Marker”，
- “不要旁白，只要画面”。

若用户要的是解说片、用生成片段做的预告片，或 talking-head 视频，应选其他流水线。

## 理念

纪录片蒙太奇是**检索优先**，而非生成优先。语料库是原材料；剪辑即思考。你在各阶段的工作是：

1. **在定稿前扩大检索空间**。建立比预想更大的语料库，让剪辑有呼吸余地。
2. **让并置自己说话**。两个平淡片段相邻，可以产生各自单独不具备的含义。
3. **相信素材**。若片段已清楚呈现某物，不要用文字或画外音再解释。
4. **节奏即信息**。按节拍切。该停留的画面要留够。快切 = 紧迫，长留 = 悲恸/重量/敬畏。

## 阶段

| 阶段 | 导演技能 | 产出 |
|-------|----------------|----------|
| `idea` | `idea-director.md` | brief（主题、调性、时长、结构） |
| `scene` | `scene-director.md` | shot_list（槽位描述 + 检索 query） |
| `assets` | `asset-director.md` | asset_manifest（语料库构建 + 各槽位选定） |
| `edit` | `edit-director.md` | edit_decisions（时间线 + 转场 + 音乐） |
| `compose` | `compose-director.md` | render_report（最终 mp4） |

每个导演技能都有独立质量门。开始该阶段前须先阅读对应导演技能。

## 核心工具

| 工具 | 作用 |
|------|------|
| `corpus_builder` | 向 Pexels/Archive.org/NASA/Wikimedia/Unsplash 扇出检索，下载 + 嵌入 + 索引 |
| `clip_search` | 为槽位排序片段、找相似集合、多样化选片 |
| `video_compose` / Remotion | 渲染最终时间线 |

Agent 通过 `corpus_builder` 与库存源交互——勿在 skill 或 director 中直接调用 adapter 类。

## 跨阶段规则

- **除非用户明确要求，否则不生成片段**。本流水线强调**真实**素材、真实质感、真实颗粒。生成的 B-roll 会破坏美学。
- **除非用户明确要求，否则不加旁白**。brief 默认应为纯画面 + 音乐。加入人声是**重大**变更，须按 Decision Communication Contract 获得用户批准。
- **先建语料库再选片**。勿对空或半成品语料库运行 `clip_search`。若检索结果弱（得分均 < 0.25），用新 query 扩充语料库。
- **记录被拒选片的决策日志**。放弃高分片段时注明原因（时代不对、过曝、情绪不对）。便于 review 阶段。

## 常见陷阱

- 把语料库当成按顺序挑选的 stock 库，而非按槽位查询的检索索引。
- 按分数而非叙事节拍排列片段。
- 让视觉重复的片段相邻。定稿前用 `clip_search` 的 `operation=diversify`。
- 切太碎。纪录片蒙太奇的生命在**停留**，不在跳切。
- 因剪辑显得“薄”而悄悄加旁白轨。改剪辑；不要用旁白掩盖。
