# 剪辑导演 — 数字人代言人流水线

## 何时使用

将已规划的主持人镜头与已产出的素材整合为一条连贯的代言人时间线。质量标准是：表达稳定、辅助层易读、CTA 落点清晰。

## 流程

### 1. 先剪主持人轨道

在添加辅助层之前，先完成核心代言人表演剪辑。若主持人剪辑本身偏弱，额外图形救不了场。

### 2. 克制地添加辅助层

仅在确有帮助时使用叠加层：

- 简短论据点，
- 产品名称，
- 价格或功能卡片，
- CTA 强化，
- 字幕。

### 3. 尊重口语节奏

在有助于强调处保留停顿。不要剪得过紧，以免数字人显得仓促或机械。

### 4. 明确规划交付物

建议的元数据键：

- `hero_cut_order`
- `cta_frame_range`
- `overlay_timing_map`
- `variant_decisions`

### 5. 质量门禁

- 主持人始终是视觉锚点，
- 叠加层时间点干净，
- 场景转场沉稳、有意图，
- CTA 只出现一次且清晰。

## 常见陷阱

- 过度剪辑以制造「能量感」。
- 让字幕、侧栏和下三分之一在同一区域争抢注意力。
- 结尾没有干净的 CTA 定格。
