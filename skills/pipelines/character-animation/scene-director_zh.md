# 场景导演 - 角色动画流水线

## 目标

产出一份 `scene_plan`，其中每个场景都适用于绑骨角色动画。

## 场景规划字段

每个场景需包含：

- 角色 ID，
- 情感节拍，
- 动作序列，
- 镜头/取景，
- 背景，
- 道具，
- 特效，
- 所需资产，
- 转场说明。

对绑骨角色表演场景使用 `type: "character_scene"`。将角色相关细节写入 `character_actions`；不要把按场景的表演数据放到任意 metadata 中，因为共享的 `scene_plan` schema 会拒绝未知的 per-scene 字段。

## 复杂度预算

优先更少、更强的镜头：

- 一个建立镜头，
- 一个动作节拍，
- 一个反应节拍，
- 一个收束节拍。

避免需要大量独特视角或复杂身体接触的场景，除非用户已批准该复杂度。
