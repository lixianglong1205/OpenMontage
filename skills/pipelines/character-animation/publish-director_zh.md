# 发布导演 - 角色动画流水线

## 目标

为最终的角色动画交付物打包，附带如实元数据，以及突出角色、易于识别的缩略图/海报帧概念。

## 要求

- 说明实际采用的视觉处理方式：本地绑定角色动画、程序化特效、Remotion/HyperFrames 渲染，或混合方案。
- 选取一张海报帧，使主角情绪清晰可读。
- 若产出为样片，须标注为样片。
- 若成片受某参考启发，应描述灵感来源，不得声称完全复刻。

## 输出

产出 `publish_log`，包含：

- 最终视频路径，
- 缩略图/海报帧说明，
- 标题创意，
- 描述文案，
- 各平台导出说明，
- 局限或后续建议。
