# 视频制作中的字体排版

> 来源：School of Motion 字体排版指南、legibility.info 视频文字规则、Wave.video 字体
> 配对研究、EBU/SMPTE 广播标准、Netflix 字幕规范、BBC 字幕指南、
> WCAG 2.1 对比度要求、Easings.net、postplanify.com 安全区数据（2026）

## 速查卡

```
TITLE SIZE:       60-90px at 1080p  |  120-180px at 4K
BODY SIZE:        40-60px at 1080p  |  80-120px at 4K
SUBTITLE SIZE:    42px+ at 1080p    |  3-5% of video height
MAX CHARS/LINE:   32-42 (subtitles) |  30 (overlays)
MAX LINES:        2 (subtitles)     |  3 (overlays)
READING SPEED:    21 chars/sec      |  160-200 WPM
TITLE SAFE:       80% of frame (192px margin at 1080p)
ACTION SAFE:      90% of frame (96px margin at 1080p)
FONT FAMILIES:    1-2 per video maximum
CONTRAST:         4.5:1 minimum, 7:1 optimal
FADE DURATION:    0.3s opacity  |  0.5-1.0s slide/scale
```

## 字体选择

### 推荐视频字体

| 类别 | 字体 | 用途 |
|----------|-------|---------|
| **正文 / 字幕** | Inter, Open Sans, Roboto, Source Sans Pro, Lato, DM Sans | 所有正文、字幕、说明文字 |
| **标题** | Montserrat Bold, Bebas Neue, Oswald Bold, Poppins Bold | 标题、章节头、关键数据 |
| **编辑风** | Playfair Display, Roboto Slab | 奢华、电影感、纪录片 |
| **系统安全** | Helvetica Neue, Arial, Avenir Next | 无法使用自定义字体时 |

### 字体配对规则

- 每个视频最多 **1–2 种字体族** — 过多会造成视觉噪音
- 将 **展示/粗体标题** 字体与 **中性正文** 字体配对
- 标题与正文字号差：至少 **大 50%**
- **无衬线** 用于动态图形与字幕（运动中更清晰）
- **衬线** 仅用于电影感标题卡与编辑类内容
- **手写/装饰** 字体：仅用于主标题，勿用于正文，勿用于运动中的文字

### 经证实的配对

| 标题 | 正文 | 风格 |
|---------|------|-------|
| Bebas Neue | Open Sans | 高冲击、社交广告 |
| Montserrat Bold | Lato | 简洁现代 |
| Oswald Bold | Raleway | 强对比 |
| Playfair Display | Inter | 编辑风 |
| Poppins Bold | Poppins Light | 同族层级 |

### 广播标准

| 区域 | 覆盖范围 | 1080p 边距 | 用途 |
|------|----------|----------------|---------|
| **标题安全区** | 画面 80% | 192px 水平，108px 垂直 | 所有文字须在此范围内 |

## 文字动画时序

### 屏幕停留时长

- 阅读速度：最少 **每秒 13 个字符** 的停留时间
- 30 字符一行：最少 **2.3 秒**
- 一般规则：**每 63 个字符 3 秒**
- 标题卡：**3–6 秒**
- 动画结束后，静止保持 **每 13 个字符 1 秒**

### 动画时长

| 动画类型 | 时长 | 使用场景 |
|---------------|----------|----------|
| 淡入/淡出 | 0.3–0.5s | 细腻、通用 |
| 滑入/缩放入场 | 0.5–1.0s | 标准动态图形 |
| 动态文字入场 | 1.0–2.0s | 醒目、动感 |
| 下三分之一入场 | 1.0–2.0s | 说话人标识 |
| 下三分之一退场 | 0.5–1.0s | 快速离场 |

### 缓动曲线

| 缓动 | Cubic Bezier | 用途 |
|--------|-------------|---------|
| **easeOutCubic** | `(0.33, 1, 0.68, 1)` | 文字入场（减速到位）— **默认选择** |
| **easeOutQuart** | `(0.25, 1, 0.5, 1)` | 更利落的入场、kinetic 字体 |
| **easeInOutQuad** | `(0.45, 0, 0.55, 1)` | 平滑位置过渡 |
| **easeInOutCubic** | `(0.65, 0, 0.35, 1)` | 缩放与透明度变化 |
| **easeInCubic** | `(0.32, 0, 0.67, 0)` | 退场（加速离开） |

**切勿对文字动画使用线性缓动** — 会显得机械。

### 揭示技巧

| 技巧 | 感受 | 最适合 |
|-----------|------|----------|
| 遮罩揭示 | 电影感 | 标题卡、高端内容 |
| 缩放弹出 | 动感 | 社交媒体、短视频 |
| 逐字错开 | 自然流动 | 动态字体排版 |
| 逐词同步 | 吸引注意 | 口播字幕、TikTok |
| 淡入淡出 | 细腻 | 专业、企业 |

## 字幕与说明文字排版

### 规格

| 参数 | 数值 | 来源 |
|-----------|-------|--------|
| 字号 | 1080p 下 42px+ | 无障碍标准 |
| 每行最大字符数 | 32–42 | 因平台而异（见下） |
| 最大行数 | 每块 2 行 | 通用标准 |
| 行距 | 1.3× | 可读性标准 |
| 背景 | 半透明黑，70–80% 不透明度 | 对比度要求 |
| 替代样式 | 白字 + 2–4px 深色描边 | 无框样式 |
| 最低对比度 | 4.5:1（白字黑底 = 21:1） | WCAG AA |
| 底边距 | 距边缘至少 60px | 移动端手势留白 |
| 画面内宽度 | 最多 90% | 标题安全区合规 |

## 下三分之一（Lower Thirds）

### 标准规格（1080p）

- 叠加区域：**1920×360px**（画面下三分之一）
- 无衬线字体（Helvetica、Open Sans、Roboto）
- 白字加投影或半透明背景条
- 姓名：粗体、较大字重
- 职务/副标题：较轻字重、较小字号

### 时序

| 阶段 | 时长 |
|-------|----------|
| 入场动画 | 1–2 秒 |
| 显示 | 3–6 秒 |
| 退场动画 | 0.5–1 秒 |

## 对比度与可读性

### WCAG 要求

| 元素 | 最低比值 | 标准 |
|---------|----------|----------|
| 正文 | 4.5:1 | WCAG AA |
| 大号文字（>18pt） | 3:1 | WCAG AA |
| 增强正文 | 7:1 | WCAG AAA |
| UI 组件 | 3:1 | WCAG 2.1 |

### 视频上的文字技巧

1. **半透明底框** — 文字后 70–80% 黑色不透明度（最可靠）
2. **文字描边** — 浅色文字外 2–4px 深色轮廓
3. **投影** — 轻微阴影增加层次（复杂背景上较不可靠）
4. **暗化区域** — 文字区域后的渐变叠加
5. **全屏叠加** — 文字密集画面使用 30–50% 暗色叠加

## 在 OpenMontage 中的应用

在 compose/asset 阶段为视频生成文字时：

1. **字体选择** — 使用上文推荐视频字体；正文优先 Inter 或 Open Sans，标题用 Montserrat Bold
2. **尺寸检查** — 1080p 下任何文字元素不得低于 40px
3. **安全区** — 所有文字在 80% 标题安全区内；竖屏/短视频使用 900×1400px 通用安全区
4. **字幕样式** — 42px+、最多 2 行、每行最多 42 字符、75% 不透明度半透明背景
5. **动画** — 入场用 easeOutCubic，动画结束后至少按每 13 字符 1 秒保持文字
6. **对比度** — 在代表性调色帧上验证最低 4.5:1；优先白字深底（21:1）
7. **平台定向** — 查阅上文平台安全区表并调整文字位置
8. **Remotion 渲染** — 所有字体族须在组件中通过 `@import` 或 `fontFamily` 加载；在 Docker/Lambda 环境中测试字体是否正常渲染
