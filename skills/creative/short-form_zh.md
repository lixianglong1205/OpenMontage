# 短视频管线（TikTok / Reels / Shorts）

> 来源：TikTok Creator Portal、Instagram for Business 博客、YouTube Shorts 文档、
> Hootsuite Social Trends Report 2025、OpusClip 2025 留存数据、Shortimize 350 亿条 Shorts
> 分析、PostPlanify 2026 安全区、Kreatli 平台指南、TTS Vibes 开场钩子统计

## 速查卡

```
ASPECT RATIO:     9:16 vertical (1080x1920)
SAFE ZONE:        900x1400px centered (universal cross-platform)
DURATION:         15s (highest completion) | 30s (best engagement) | 60s (most flexible)
HOOK:             First 1-2 seconds — visual or text pattern interrupt
CAPTIONS:         Mandatory (85% watch muted on mobile)
TEXT SIZE:         42px+ minimum, bold sans-serif
PACING:           Visual change every 1-3 seconds
TARGET LUFS:      -14 LUFS, true peak -1 dBTP
MUSIC:            120-140 BPM for energetic, 90-110 for explainers
```

## 平台安全区（1080x1920）

| 平台 | 安全区 | 顶部不可用 | 底部不可用 | 右侧不可用 |
|----------|-----------|----------|-------------|------------|
| TikTok | 900x1492 | 108px | 320px | 120px |
| Instagram Reels | 996x1400 | 210px | 310px | 84px |
| YouTube Shorts | 984x1500 | 120px | 300px | 96px |
| Facebook Reels | 1080x1520 | 100px | 300px | 60px |

**通用安全区：居中 900x1400px** — 适用于各平台。

**底部不可用区至关重要** — 平台 UI（评论、分享按钮、字幕）会覆盖底部 300–320px。切勿在此放置重要内容。

## 时长策略

| 时长 | 平均完播率 | 最适合 |
|----------|-------------------|----------|
| 0-15s | 92% | 单一事实、快技巧、视觉梗 |
| 16-30s | 84% | 讲清一个概念、前后对比 |
| 31-60s | 68% | 迷你教程、分步演示、故事线 |
| 60s+ | 48% | 深度讲解，仅当留存结构足够强时 |

**各平台甜点：**
- TikTok：21–34 秒利于完播；60–180 秒利于总观看时长
- Reels：15–30 秒利于病毒传播；60–90 秒互动最高
- Shorts：双峰 — 约 13 秒或完整 60 秒（Shortimize 350 亿次观看分析）

**关键公式：** 45 秒视频 70% 完播（31.5 秒观看）优于 15 秒视频 40% 完播（6 秒）。算法奖励的是总观看时长。

## 1 秒钩子

**超过 70% 的 TikTok 用户在 3 秒内决定划走或留下**（平均决策点：1.7 秒）。钩子必须即时出现。

### 3 秒留存与算法影响

| 3 秒留存 | 算法效果 | 播放倍数 |
|-------------------|-------------------|-----------------|
| 低于 60% | 几乎不推广 | 1.0x（基线） |
| 60-70% | 平均分发 | 1.6x |
| 70-85% | 最佳触达 | 2.2x |
| 85%+ | 病毒潜力 | 2.8x |

### 留存检查点

| 时间点 | 目标留存 |
|-----------|-----------------|
| 3 秒 | 70%+ |
| 15 秒 | 60%+ |
| 30 秒 | 50%+ |

### 钩子技巧

| 技巧 | 示例 | 适用场景 |
|-----------|---------|-------------|
| **屏幕粗体文字** | 「别再这样做了…」（第 1 帧出现文字） | 始终适用 — 静音也能靠文字钩子 |
| **模式打断** | 意外画面、跳切、色彩闪动 | 抓注意力 |
| **提问** | 「为什么 X 会发生？」（文字 + 旁白） | 教育类 |
| **结果先行** | 先展示成品，再讲怎么做 | 教程/操作类 |
| **争议表述** | 「大家都搞错了」 | 互动诱饵 |

### 钩子规则

1. **第 1 帧必须有视觉吸引力** — 不要空白开场、不要 Logo、不要「嘿大家好」
2. **文字在 0.5 秒内出现** — 观众会先扫文字再听
3. **人声立即开始** — 不要无声铺垫
4. **第 1 帧要有运动** — 静态开场容易被划走

## 节奏

| 规则 | 数值 | 原因 |
|------|-------|-----|
| 画面变化频率 | 每 1–3 秒 | 移动端注意力 |
| 每分钟切镜数 | 20–40 | 比长视频快 2–3 倍 |
| 屏幕文字 | 每段文字 2–4 秒 | 快速阅读节奏 |
| 禁止长时间静止 | 最多 3 秒 | 再长会像卡住 |
| 变速 | 铺垫 1.2–1.5x，高潮 1.0x | 压缩无聊段落 |

**节奏对留存的影响：**
- 每 2–4 秒一次模式打断：**平均留存 58%**
- 静态 Talking Head（无打断）：**平均留存 41%**
- 仅靠节奏就有 **41% 相对提升**

## 文字与字幕

### 字幕必选

**80% 的短视频观众静音观看**（2025 年中数据）。准确字幕平均 **留存高 12%**。字幕不是可选项。

| 参数 | 数值 |
|-----------|-------|
| 字号 | 1080p 下 42px+ |
| 字重 | 粗体 |
| 字体 | 无衬线（Inter、Montserrat、Poppins） |
| 背景 | 半透明黑（75% 不透明度）或 3px 描边 |
| 位置 | 居中或偏下居中，在安全区内 |
| 每行最多字符 | 30 |
| 最多行数 | 2 |
| 逐词高亮 | 建议用于提升互动 |

### 屏幕文字（非字幕）

- 放在安全区 **上方 40%**（中心线以上）
- 粗体、高对比（白字深底或色块背景）
- 每段文字最多 3–5 个词
- 入场动画（缩放弹出或淡入，0.2–0.3s）

## 音频

| 元素 | 电平 | 说明 |
|---------|-------|-------|
| 旁白 | 峰值 -12 至 -14 dB | 主轨 |
| 音乐 | -22 至 -26 dB | 比长视频更低 — 空间更小 |
| 音效 | -18 至 -14 dB | 仅短促 pop/whoosh |
| 目标 LUFS | -14 LUFS | 与 YouTube 长视频相同 |
| 真峰值 | -1 dBTP | TikTok/Instagram 规格 |

### 音乐选择
- **高能内容：** 120–140 BPM
- **讲解类：** 90–110 BPM
- **贴合热门音频模式** — 短视频观众预期音乐靠前
- **音乐应立即开始** — 不要无声片头

### 旁白语速
- 短视频 **180–200 WPM**（快于长视频的 150–160）
- 有能量、有紧迫感
- 不要长停顿 — 空白 = 划走

## 结构模板

### 15 秒快技巧
```
[0-1s]   HOOK: Bold text + voice starts immediately
[1-3s]   CONTEXT: One sentence setup
[3-12s]  CONTENT: The tip/fact/technique (show, don't tell)
[12-15s] PAYOFF: Result or CTA text overlay
```

### 30 秒讲解
```
[0-1s]   HOOK: Pattern interrupt or question
[1-5s]   PROBLEM: Why this matters
[5-22s]  SOLUTION: Step-by-step with visual changes every 2-3s
[22-28s] RESULT: Show the outcome
[28-30s] CTA: Follow/share/comment prompt
```

### 60 秒迷你教程
```
[0-2s]   HOOK: Show finished result first
[2-8s]   SETUP: "Here's how to do X in Y steps"
[8-45s]  STEPS: 3-5 steps, ~8s each, visual change per step
[45-55s] RESULT: Before/after or final demo
[55-60s] CTA + LOOP: End connects back to start for replay
```

## 在 OpenMontage 中的应用

制作短视频时：

1. **在 compose 阶段将输出分辨率设为 1080x1920**（9:16）
2. **所有文字保持在 900x1400px 安全区内** — 画面居中
3. **字幕必选** — 使用 `subtitle_gen` 并做逐词时间轴
4. **第 1 帧即钩子** — 文字叠加 + 人声立即开始，不要片头
5. **每 1–3 秒一次画面变化** — 快切、缩放、文字弹出
6. **旁白 180–200 WPM** — 快于长视频
7. **音乐立即开始** — `music_gen` 设为高能 BPM（110–140）
8. **目标 15–30 秒** 以获得最高完播率
9. **用手机测试** — 发布前按真实移动端尺寸预览
