# 场景示例

来自 3Blue1Brown 风格视频的示例场景拆解。

## 示例 1：解释点积

### 场景 1：提出问题
**时长**：约 30 秒
**目的**：用悬念吸引观众

**视觉元素**
- 两个向量 a 和 b，以箭头绘制
- 点积公式：a · b = |a||b|cos(θ)
- 问号动画

**内容**
开场展示两个向量。显示公式。提出问题：「为什么把分量相乘再相加，会得到与向量夹角相关的结果？」

**旁白要点**
语气：好奇、略带困惑。强调公式看似任意。

**技术要点**
- 向量使用 Arrow
- 公式使用 MathTex
- 对 cos(θ) 项使用 Indicate()

---

### 场景 2：几何解释
**时长**：约 90 秒
**目的**：展示投影解释

**视觉元素**
- 向量 a（水平，蓝色）
- 向量 b（倾斜，绿色）
- b 在 a 上的投影（虚线）
- 直角标记
- 长度标注

**内容**
说明 a · b 等于 |a| 乘以 b 在 a 上的投影。动画展示投影「落下」。从几何上说明这等于 |a||b|cos(θ)。

**旁白要点**
「点积衡量一个向量在另一个向量方向上有多少分量。」

**技术要点**
- 投影使用 DashedLine
- 直角使用 RightAngle mobject
- 用 animate.rotate() 展示不同夹角

---

### 场景 3：数值联系
**时长**：约 60 秒
**目的**：连接几何与代数

**视觉元素**
- 坐标网格
- 向量 a = [a₁, a₂]
- 向量 b = [b₁, b₂]
- 高亮分量

**内容**
在网格上展示向量并标注分量。说明为何 a₁b₁ + a₂b₂ 与几何解释一致。使用具体数值演示。

**旁白要点**
慢慢演算。「我们来看看代数为何与几何一致。」

**技术要点**
- 使用 NumberPlane 或 Axes
- 分量标注使用 Brace
- 方程步骤使用 TransformMatchingTex

## 示例 2：傅里叶级数入门

### 场景 1：引子
**时长**：约 45 秒
**目的**：展示令人惊讶的结果

**视觉元素**
- 方波（尖角）
- 光滑正弦波之和
- 二者之间的 morph 动画

**内容**
「你可以用完全光滑的正弦波，拼出带尖角的方波。」先展示结果，再承诺解释原理。

**旁白要点**
语气：惊奇、略带不信。应让观众感到意外。

**技术要点**
- 波形使用 ParametricFunction
- morph 使用 Transform 动画
- 可考虑展示 1、3、5 项逐步叠加

---

### 场景 2：基本构件
**时长**：约 120 秒
**目的**：引入正弦波作为基

**视觉元素**
- 单一正弦波
- 频率可视化（振荡更快）
- 振幅可视化（更高/更矮）
- 相位可视化（左右平移）

**内容**
介绍三个参数：频率、振幅、相位。分别展示，再组合。

**旁白要点**
放慢节奏。「正弦波有三个可以调节的旋钮……」

**技术要点**
- 参数动画使用 ValueTracker
- 用 Updater 让波形响应 tracker
- 为各参数添加标签

---

### 场景 3：叠加
**时长**：约 90 秒
**目的**：说明波可以相加

**视觉元素**
- 两条正弦波（不同颜色）
- 它们的和（第三种颜色）
- 逐点相加可视化

**内容**
说明相加即在每一点把高度相加。用两个特定频率组合演示。

**旁白要点**
「波相加很简单——在每一点，把高度加起来就行。」

**技术要点**
- 三条函数图组成 VGroup
- 在特定 x 处用竖线展示相加
- 动画演示相加过程

## 示例 3：矩阵作为线性变换

### 场景 1：网格变换
**时长**：约 60 秒
**目的**：视觉基础

**视觉元素**
- 二维坐标网格（NumberPlane）
- 基向量 î 与 ĵ（彩色箭头）
- 网格线变形

**内容**
展示网格。高亮 î (1,0) 与 ĵ (0,1)。施加变换——观察整个网格移动，并跟踪基向量落点。

**旁白要点**
「看看施加这个变换时网格会怎样。注意每个点如何移动。」

**技术要点**
- 使用带可见网格线的 NumberPlane
- 使用 apply_matrix() 方法
- 基向量在视觉上保持区分

---

### 场景 2：基向量决定一切
**时长**：约 90 秒
**目的**：关键洞见

**视觉元素**
- 变换后的 î 与 ĵ
- 任意向量 v 作为组合
- v = xi + yj 可视化

**内容**
说明只要知道 î 和 ĵ 落在哪里，就知道任意向量落在哪里。因为 v = xi + yj，变换后的 v = x(新 î) + y(新 ĵ)。

**旁白要点**
「关键洞见在这里……」在揭示前营造期待。

**技术要点**
- 向量加法动画（首尾相接）
- 系数缩放动画
- 组合使用 TransformMatchingShapes

## 场景转场模式

### 缩放聚焦
```
Full scene → Zoom into detail → Explain → Zoom out
```

### 并排构建
```
Empty left | Empty right
Add to left | Compare
Add to right | Connect them
```

### 变换链
```
Object A → Transform → Object B → Transform → Object C
(Maintain visual continuity throughout)
```

### 重置再构建
```
Complex scene → Clear/fade most → Focus on one element → Build new complexity
```
