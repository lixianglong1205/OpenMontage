# 章节

本文件定义了所有章节及其排序、影响级别和描述。
括号内的章节 ID 是用作规则分组的文件名前缀。

---

## 1. 消除瀑布流（async）

**影响：** CRITICAL  
**说明：** 瀑布流（waterfall）是头号性能杀手。每一次顺序 `await` 都会叠加完整的网络延迟。消除瀑布流能带来最大的性能收益。

## 2. 包体积优化（bundle）

**影响：** CRITICAL  
**说明：** 减小初始包体积可提升可交互时间（Time to Interactive）和最大内容绘制（Largest Contentful Paint）。

## 3. 服务端性能（server）

**影响：** HIGH  
**说明：** 优化服务端渲染与数据获取可消除服务端瀑布流并缩短响应时间。

## 4. 客户端数据获取（client）

**影响：** MEDIUM-HIGH  
**说明：** 自动去重与高效的数据获取模式可减少冗余网络请求。

## 5. 重渲染优化（rerender）

**影响：** MEDIUM  
**说明：** 减少不必要的重渲染可降低无效计算并提升 UI 响应性。

## 6. 渲染性能（rendering）

**影响：** MEDIUM  
**说明：** 优化渲染过程可减少浏览器需要完成的工作量。

## 7. JavaScript 性能（js）

**影响：** LOW-MEDIUM  
**说明：** 对热路径进行微优化，累积起来可带来可观的提升。

## 8. 高级模式（advanced）

**影响：** LOW  
**说明：** 针对特定场景的高级模式，需要谨慎实现。
